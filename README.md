# 🌲 cs-skill-tree

简体中文 | [English](docs/README.en.md)

**一张能点亮的 CS 星图：你在圆心，会的技能是亮着的星，亮区的边缘就是你的能力边界。**

- 225 颗星（183 个知识点 + 42 个语言 / 框架 / 平台），325 条前置关系。越靠内越基础，一圈圈往外是进阶
- 每颗星写明**学会的标志**，对照着自评，做得到才点亮
- **能力边界**：前置都会了、自己还没学的星，青色呼吸着，就是你现在最该学的
- 外圈的信标是职业方向。选一个当**目标**，它要学的星会标出顺序，哪片星域亮了你就离哪个方向近
- 选中一颗星，画出它一直到圆心的前置路线和它能解锁的星；点亮时光顺着线流到新解锁的星
- 进度存在浏览器，可以导出、导入、分享链接、回放成长；也可以跑带数据库的服务端版本

👉 https://theowang42.github.io/cs-skill-tree/

## 怎么用

1. 第一次来点 **开始自评**，打开“快速点亮”，从圆心附近的星开始，把会的点亮
2. 点外圈的一个信标，**设为我的目标**
3. 顶栏的 **下一颗** 会带你飞到最该学的那颗星；面板告诉你离目标还差多少

滚轮缩放、拖动平移。快捷键：`/` 搜索 · `Q` 快速点亮 · 选中星时 `D` 学会了、`L` 在学、`X` 清除 · `Esc` 返回 · `1` 回到我的星域 · `0` 看全图

## 本地运行

需要 Node 22.18 以上（用到内置的 `node:sqlite` 和直接运行 TypeScript），不需要装数据库。

```bash
npm ci
npm run dev        # 只有前端，进度存浏览器
npm run dev:api    # 前端 + API，进度存 SQLite（data/cs-skill-tree.db）
npm test
```

## 改内容

所有内容都在 `db/seed/*.sql`，一个技能一行。改完跑 `npm run db:build`，它会重建数据库并体检：
前置成环、连反了层、编号断档、内容缺失、多余的前置都会报出来。

数据库结构、命令、API 和前端结构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。课程主要参考 [csdiy.wiki](https://csdiy.wiki/)。
