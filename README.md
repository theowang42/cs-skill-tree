# 🌲 cs-skill-tree

简体中文 | [English](docs/README.en.md)

**一棵能点亮的计算机技能树：把你会的点亮，随时看清自己的能力边界。**

- 225 个技能（183 个知识点 + 42 个语言 / 框架 / 平台），330 多条前置关系，从“变量与控制流”一直到“共识算法”
- 每个技能写明**学会的标志**，对照着自评，做得到才点亮
- **能力边界**：前置都会了、自己还没学的技能，就是你现在最该学的
- 选一个**目标方向**（Agent 开发、后端、操作系统内核……），标出要学的技能、学习顺序和就绪度
- 进度存在浏览器，可以导出、导入、生成分享链接；也可以跑带数据库的服务端版本

👉 https://theowang42.github.io/cs-skill-tree/

![点亮已掌握的技能后，选中「事务与隔离级别」：左边是它的前置和学会的标志，树上画出前置路线，琥珀色是目标「后端开发」的学习顺序](docs/screenshot.jpg)

## 怎么用

1. 第一次来点 **开始自评**，打开“快速点亮”，从最下面的基础层开始，把会的技能点亮
2. 在最上面的应用层选一个方向，点 **设为我的目标**
3. 左栏告诉你：离目标还差多少、**下一步可以学**什么、你的能力边界在哪

快捷键：`/` 搜索 · `Q` 快速点亮 · 选中技能时 `D` 学会了、`L` 在学、`X` 清除 · `Esc` 返回

## 本地运行

需要 Node 22.18 以上（用到内置的 `node:sqlite` 和直接运行 TypeScript），不需要装数据库。

```bash
npm ci
npm run dev        # 只有前端，进度存浏览器
npm run dev:api    # 前端 + API，进度存 SQLite（data/cs-skill-tree.db）
npm test
```

## 改内容

所有内容都在 `db/seed/*.sql`，一个技能一行。改完跑 `npm run db:build`，它会重建数据库并体检：
前置成环、连反了层、编号断档、内容缺失、多余的前置都会报出来。

数据库结构、命令、API 和前端结构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。课程主要参考 [csdiy.wiki](https://csdiy.wiki/)。
