# 美术风格：纸上的技能树

一句话：**一张印在白纸上的技能树示意图。** 像动作游戏的天赋树，但只用黑和灰。

参考物：游戏天赋树的分支结构、说明书里的线框示意图、javascript.info 那种只有正文和链接的教程页。
情绪：清楚、安静、一眼看懂。点亮一个技能就是把一个空方块涂黑。

## 颜色

| 名字 | 值 | 用在哪 |
| --- | --- | --- |
| 纸 `--paper` | `#ffffff` | 底色 |
| 墨 `--ink` | `#111111` | 文字、已掌握的节点、能学的节点的框、按钮 |
| 墨·淡 `--ink-2` | `#666666` | 次要文字、分支名 |
| 墨·极淡 `--ink-3` | `#9a9a9a` | 等级名、够不着的节点里的图标和名字 |
| 线 `--line` | `#d9d9d9` | 够不着的节点的框、未点亮的连线 |
| 线·淡 `--line-2` | `#ededed` | 等级之间的横线、列表分隔 |
| 洗 `--wash` | `#f4f4f4` | 悬停的底 |
| 朱砂 `--goal` | `#d94f3d` | 只用在两处：顶栏的目标名、“下一个”节点上方的小三角 |

规则：整张图只有黑白灰。唯一的颜色是朱砂，只给目标。没有渐变、没有阴影、没有圆角大于 4px 的东西。

## 节点

52×52 的方块，1.25px 边框，4px 圆角，里面一个 24px 的线条图标，下面 11px 的名字。
图标按所属分支（知识领域）统一；工具用自己的 logo。

| 状态 | 画法 |
| --- | --- |
| 够不着 | 浅灰框，浅灰图标和名字 |
| 能学 | 黑框 1.5px，黑图标，黑名字 |
| 在学 | 黑虚线框 |
| 已掌握 | 实心黑，白图标，名字加粗 |
| 选中 / 悬停 | 框加粗到 2.5px；其余节点淡到 22% |
| 目标里最该学的 | 方块上方一个朱砂小三角 |

## 结构

- **行 = 等级**。入门、基础、进阶、专精、前沿，自上而下五个带，带之间一根淡线，带名在最左边。同一行的技能在同一个高度。
- **列 = 分支**。每个知识领域一列，列名在顶上。相关的分支挨着。
- **线 = 前置**。从前置的底边指向后继的顶边，线尾一个小箭头。同一列竖直，跨列走一条 S 形。
  同一分支里的线一直画；跨分支的线只在选中或悬停时画，免得横穿全图。
- 已掌握之间的线是黑的，已掌握到能学的是中灰，其余浅灰。

## 字

- Noto Sans SC，没有衬线。
- 节点名 11px；分支名 13px 字距 0.08em；等级名 12px 字距 0.3em。缩得很小时只剩分支名和等级名，放大后名字才出现。
- 面板标题 24px 700；正文 14.5px；小标题 12px 字距 0.15em 灰色。

## 面板

点进去只有：所属分支和等级、名字、一句话、三段开关（没学 / 在学 / 已掌握）、“去哪学”的链接、“先会”的前置名字。
没有列表轰炸。方向的面板同理：一句话、离它多远、设为目标、几个代表项目的链接。

## 壳

- 顶栏是一行字：左边名字和“已掌握 / 总数”，右边快速点亮、目标、下一个、搜索。没有背景没有边框。
- 右侧面板：白底，左边一根黑线。
- 右下角四个按钮：放大、缩小、看我点亮的、看全图。一个黑框包着。
- 第一次打开：镜头停在入门和基础的前几个分支，底部一行提示。

## 动效

- 过渡 0.3 到 0.35s。点亮时方块弹一下（0.8 → 1.12 → 1），新解锁的线上有一道短划流过去。
- 禁止循环动画。
