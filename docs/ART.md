# 美术风格：纸上的技能树

一句话：**一张印在白纸上的技能树示意图。** 像动作游戏的天赋树，但只用黑和灰。

参考物：游戏天赋树的分支结构、说明书里的线框示意图、javascript.info 那种只有正文和链接的教程页。
情绪：清楚、安静、一眼看懂。点亮一个技能就是把一个空方块涂黑。

## 颜色

| 名字 | 值 | 用在哪 |
| --- | --- | --- |
| 纸 `--paper` | `#ffffff` | 底色 |
| 墨 `--ink` | `#111111` | 文字、已掌握的节点、能学的节点的框、按钮 |
| 墨·淡 `--ink-2` | `#666666` | 次要文字、分支名 |
| 墨·极淡 `--ink-3` | `#9a9a9a` | 等级名、够不着的节点里的图标和名字 |
| 线 `--line` | `#d9d9d9` | 够不着的节点的框、未点亮的连线 |
| 线·淡 `--line-2` | `#ededed` | 等级之间的横线、列表分隔 |
| 洗 `--wash` | `#f4f4f4` | 悬停的底 |
| 朱砂 `--goal` | `#d94f3d` | 只用在两处：顶栏的目标名、“下一个”节点上方的小三角 |

规则：整张图只有黑白灰。唯一的颜色是朱砂，只给目标。没有渐变、没有阴影、没有圆角大于 4px 的东西。

## 节点

64×64 的圆角方块（12px 圆角），里面一个 28px 的图标，下面 13px 的名字。
**每个技能一个自己的图标**：语言、框架、工具用官方 logo（Simple Icons），其余用 Lucide 里意思最贴的那个。体检会拒绝两个技能共用图标。

技能的颗粒度：**能写进简历的一项扎实能力**，比如 Python、Docker、PostgreSQL、Linux 系统编程、PyTorch。知识点（哈希表、虚拟内存）不单独成节点。

| 状态 | 画法 |
| --- | --- |
| 够不着 | 浅灰框，浅灰图标和名字 |
| 能学 | 黑框 1.5px，黑图标，黑名字 |
| 在学 | 黑虚线框 |
| 已掌握 | 实心黑，白图标，名字加粗 |
| 选中 / 悬停 | 框加粗到 2.5px；其余节点淡到 22% |
| 目标里最该学的 | 方块上方一个朱砂小三角 |

## 结构

- **左边是分支列表**，中间一次只看一个分支，像游戏里切换天赋页。
- **行 = 等级**：入门、基础、进阶、专精、前沿，五行永远都在，同一个等级在每个分支里都在同一个高度。
- **线 = 分支内的前置**：从前置往下走，在两行之间拐一个圆角，再落到后继的顶上，像电路图。不画箭头，方向永远是从上往下。
- 跨分支的前置不画线，列在分支标题下面一行“先要会”，用小标签表示，状态和节点一样（黑底已掌握、黑框能学、灰的够不着）。
- 悬停或选中一个节点：它的前置路线和它解锁的节点保持清楚，其余淡到 28%。

## 字

- Noto Sans SC，没有衬线。
- 节点名 13px；分支列表 14px；等级名 12px 字距 0.3em。
- 面板标题 24px 700；正文 14.5px；小标题 12px 字距 0.15em 灰色。

## 面板

点进去只有：所属分支和等级、名字、一句话、三段开关（没学 / 在学 / 已掌握）、“去哪学”的链接、“先会”的前置名字。
没有列表轰炸。方向的面板同理：一句话、离它多远、设为目标、几个代表项目的链接。

## 壳

- 顶栏是一行字：左边名字和“已掌握 / 总数”，右边快速点亮、目标、下一个、搜索。下面一根浅线。
- 左边分支列表：图标、名字、已掌握数；当前分支是黑底白字；目标还差几个用一个朱砂小圆标出。
- 右侧面板：选中节点时打开，树往左让，不盖住。
- 手机上分支列表变成顶上一排横向滚动的标签，面板变成底部抽屉。

## 动效

- 过渡 0.3 到 0.35s。点亮时方块弹一下（0.8 → 1.12 → 1），新解锁的线上有一道短划流过去。
- 禁止循环动画。
