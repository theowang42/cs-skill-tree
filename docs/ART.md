# 美术风格：纸上的技能树

一句话：**一套印在白纸上的天赋树。** 像游戏里一个职业有好几页天赋：一个领域一页，页签从左到右是学的先后（地基 → Web 开发 → 客户端与游戏 → 底层系统 → 安全 → 数据与量化 → 机器学习 → 大模型 → AI Infra）。每一页最下面是“你”，一行一行往上长，大量一条条的链，只在关键节点分叉，最上面一行是挂在这个领域的职业。只用黑和灰。

参考物：游戏天赋树的分支结构、说明书里的线框示意图、javascript.info 那种只有正文和链接的教程页。
情绪：清楚、安静、一眼看懂。点亮一个技能就是把一个空方块涂黑。

## 颜色

| 名字 | 值 | 用在哪 |
| --- | --- | --- |
| 纸 `--paper` | `#ffffff` | 底色 |
| 墨 `--ink` | `#111111` | 文字、已点亮的节点、能点亮的节点的框、按钮 |
| 墨·淡 `--ink-2` | `#666666` | 次要文字、分支名 |
| 墨·极淡 `--ink-3` | `#9a9a9a` | 等级名、够不着的节点里的图标和名字 |
| 线 `--line` | `#d9d9d9` | 够不着的节点的框、未点亮的连线 |
| 线·淡 `--line-2` | `#ededed` | 等级之间的横线、列表分隔 |
| 洗 `--wash` | `#f4f4f4` | 悬停的底 |
| 线·未点亮 `--off-line` | `#b9b9b9` | 还够不着的节点的框和枝，看得清但不抢眼 |
| 墨·未点亮 `--off-ink` | `#6b6b6b` | 还够不着的节点的图标和名字 |

规则：只有黑、白和几档灰，没有任何别的颜色。要强调就用黑和粗，要退后就变淡。没点亮的不能灰到看不见：框是中灰，图标和名字是深灰。

## 节点

直径 62 的圆，里面一个 28px 的图标，下面 14px 的名字。
**编程语言是语言天赋**（Python、C、C++、C#、Rust、Go、Java、Kotlin、Swift、Dart、JavaScript、TypeScript、SQL、Shell、CUDA），画成尖朝上的六边形，一眼和普通技能分开。名字直接说它是什么（数据结构、操作系统、PyTorch），不写课号。
**每个节点一个自己的图标**：语言、框架、工具用官方 logo（Simple Icons），其余用 Lucide 里意思最直白的那个。体检会拒绝两个节点共用图标。

颗粒度：**能写进简历的一项扎实能力**。计算机核心课（数据结构、计算机系统、操作系统、计算机网络……）也是节点，链接指向公认最好的那门课。知识点（哈希表、虚拟内存）不单独成节点。

**只有两种状态：点亮了，和没点亮。** 没点亮的再按前置分成能点和还够不着，只是画法不同。
**前置都点亮了才能点亮**；取消一个，依赖它的一起熄灭（可以撤销）。够不着的节点在面板里按钮是灰的。

| 状态 | 画法 |
| --- | --- |
| 够不着 | 近白底、中灰框，深灰图标和名字（看得清） |
| 能点亮 | 白底黑框 2.5px，外面一圈黑虚线（空着等你点的技能槽），黑图标黑名字；悬停时底色变浅灰 |
| 已点亮 | 黑底白图标，名字加粗；外面一圈向外放射的黑色短线（24 道，长短相间，像太阳的光芒），整圈慢慢旋转，9 秒一圈；每个节点转到的角度不同。点亮那一刻弹一下，一圈波纹和八道光芒往外散开 |
| 选中 / 悬停 | 只亮它往下的全部依赖（要先点亮的）：都画成黑边、黑图标、黑名字，连线变黑；其余淡到 45% |

## 结构

- **从下往上长。** 最下面正中是“你”：圆里上面是点亮了几个技能，下面一行小字“我的进度”，外面一圈进度环是总进度；点亮过东西后它变黑，外面一圈光芒慢慢转。鼠标放上去，树上只亮下一步能点亮的技能；点它打开“我的进度”。从它出发连到第一行的编程入门、Linux、微积分；往上一行深一层，行与行等距。
- **一列一列**：每个节点只画一根枝，连到它的主前置。所以画出来是一条条竖直的链，比如 Python → NumPy → 机器学习 → 深度学习 → PyTorch → Transformer → 从零实现 GPT → vLLM 推理 → 分布式推理。只有编程入门、Python、计算机系统这种关键节点才一分多。
- **左右的顺序**：Web、客户端、数据在左，AI 在中间，地基、底层系统和安全在右（职业天赋树里兄弟按这个排）。
- **其余前置不画线**（会横穿整张图）。悬停或选中一个技能时，只亮它往下的全部依赖，都是黑边；面板里用小节点列出下一级。
- **最上面一行是职业，也就是终极节点**：17 枚，覆盖计算机毕业生的主要去处，粒度统一到招聘时的岗位名（对齐“后端工程师”这一级）。一枚双圈的奖章（外面一圈粗线、里面紧贴一圈细线），比普通节点大一号，中间是职业图标；外面一圈进度环，要学的技能点亮多少就黑多少；上面是加粗的名字，下面一行是“已点亮几个 / 一共几个”。各个徽章要点亮的技能数控制在 20 到 34 个之间。徽章出现在它挂的技能所在的那一页，在那一列的顶上，从挂的技能一根竖线直直连上去。不用选职业：要学的都点亮了，它自己就达成——徽章变黑、图标变白，外面一大圈光芒慢慢转；达成那一刻徽章弹一下，两圈波纹和十六道光芒冲出去，底下提示“达成职业”。点它，树上亮出它要学的全部技能。
- **枝条横平竖直**：从父节点头顶往上，到两行中间横着走过去，再往上停在孩子的名字下面；只有一个孩子时就是一根直线。线绕开名字。两头都点亮的枝是黑色的粗线；从已点亮长向能点亮的是黑线，告诉你下一步往哪走；其余是中灰。
- **跨领域的前置**：主前置在别的领域的技能，从“你”直接连出来，名字下面一行小字“先会 某某”，点它跳到那一页。
- **打开时**按原大小（最多装满宽度），“你”贴着屏幕底下，往上滚着读，像 roadmap.sh；点“看全图”装下这一整页。
- **职业页**只画这个职业要学的技能和它的徽章，画法完全一样。首页每个职业一棵小树，只画形状和图标。

## 字

- Noto Sans SC，没有衬线。
- 节点名 14px；方向名 14px 粗体。
- 面板标题 24px 700；正文 14.5px；小标题 12px 字距 0.15em 灰色。

## 面板

点进去是一张**技能卡**，像游戏里的技能说明：

- 卡头：双线框里一个放大的图标槽（和树上同一个形状），旁边是“技能 / 语言天赋 · 领域 · 第几层”、名字、状态牌（未解锁 / 可点亮 / 已点亮）。
- 一句话。
- 一块黑色的大按钮“点亮”，按下去会往下沉；已点亮时变成白底“已点亮”，悬停换成红字“熄灭”；前置没点亮时是灰的，按不了。
- 先点亮上一级：画成和树上一样的小节点（圆或六边形、图标、点亮状态），下面写名字和“已点亮 / 未点亮”，点它跳过去。
- 去哪学：一两个链接。
没有列表轰炸。职业的面板同理：一句话、离它多远、要点亮的技能、几个代表项目的链接。

## 壳

- 顶栏是一行字：左边名字（回首页）和“已点亮 / 总数”（打开我的进度）；职业天赋树里右边多一个“全部技能”。
- 顶栏下面一排领域页签，每个写着“已点亮 / 一共”，从左到右是学的先后。下面一根浅线。
- 整个下方都是树。滚轮或拖动平移，按住 Ctrl / ⌘ 滚动或双指捏合缩放，右下角放大、缩小、看全图。
- 右侧面板：选中节点时打开，网往左让，不盖住。手机上是底部抽屉。

## 动效

- 过渡 0.3 到 0.35s。点亮时节点弹一下（0.85 → 1.12 → 1），波纹和光芒散开一次。
- 打开时树从“你”往上长出来：枝条一段段画出来，节点跟着浮现，越往上越晚（最上面约 1 秒）。
- 循环动画两种，都很慢、很淡：
  - 已点亮节点外面那圈光芒慢慢旋转（9 秒一圈）。
  - 两头都点亮的枝条上，一小段白光沿着线从下往上流（2.6 秒一趟，越往外越晚出发）。
- 系统设置了减少动画时，这些全部停下。
