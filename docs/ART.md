# 美术风格：墨夜星盘

一句话：**靛青的夜里一圈圈星云，你是中间的光源，照到哪里，哪里的星才存在。**
不是霓虹太空，不是赛博，不是仪表盘。

参考物：深空照片里的星云层次、《天文图》石刻拓片、金箔点在深蓝宣纸上。
情绪：安静、克制、有仪式感。点亮一颗星像在纸上贴一片金箔，不像按下一个按钮。

画面里只有三种东西：**星云**（知识领域，一团柔光）、**星**（技能）、**星座线**（前置关系，从里指向外，带一个小箭头）。
其余都不画：没有圈、没有扇区线、没有角标、没有图例、没有圆心的符号。

## 颜色（全部从这里取，不另造）

| 名字 | 值 | 用在哪 |
| --- | --- | --- |
| 夜 `--sky` | `#0a0f1e` | 底色。靛青偏黑，不是纯黑 |
| 夜·浅 `--sky-2` | `#111830` | 卡片、圆心、星的暗底 |
| 墨 `--ink` | `#e9e3d3` | 正文。暖的米白，像纸 |
| 墨·淡 `--ink-2` | `#9a97a3` | 次要文字 |
| 墨·极淡 `--ink-3` | `#4b5068` | 刻度线、影子星、分隔 |
| 金箔 `--lit` | `#e4b458` | 已掌握的星、已探索的星域 |
| 金·亮 `--lit-2` | `#f7e2a8` | 星的中心、金色文字 |
| 青瓷 `--edge` | `#9fd6c9` | 能力边界。柔和的青，不是电光蓝 |
| 朱砂 `--goal` | `#d9644e` | 目标方向、步数。印章的红 |

规则：一屏里最多三种有彩度的颜色同时出现（金、青、朱砂）。其余全是墨的深浅。
不用渐变做装饰，只用渐变做光晕。不用毛玻璃。不用阴影，用一根发丝线分隔。

## 星云

- 每个知识领域一种压暗的色相（靛、青、紫、玫瑰、琥珀、蓝、苔绿、赭），不透明度 0.1 到 0.26，叠在一起像深空照片。
- 星云沿圈方向拉长，一个领域在一圈上是一团。只有被照到（里面有看得见的星）的星云才显现。
- 五个等级是五圈同心的星云带：入门、基础、进阶、专精、前沿。圈线只有 0.05 的不透明度，拉近时圈顶有一个两个字的等级名。

## 线条

- 一律发丝线：0.75px，墨·极淡，不透明度 0.1 到 0.6。
- 星座线有方向：从前置指向它解锁的技能，线尾一个 5px 的小箭头，颜色跟线。
- 两颗亮星之间用金箔色 1px；亮星到边界星用青瓷色；边界星到影子用墨·极淡；再往外的不画。
- 虚线只用在一种地方：悬停时指向它解锁的星。

## 星的画法

| 状态 | 画法 |
| --- | --- |
| 已掌握 | 四芒星（金箔），外面一圈柔和的金色光晕。大小按被依赖的多少略有差别 |
| 在学 | 四芒星的轮廓线（金），中心空 |
| 能力边界 | 小圆点（青瓷），外面一圈极细的青色环。每隔几秒轻轻闪一下，不同步 |
| 影子 | 极小的墨·极淡圆点，没有名字。告诉你“那边还有” |
| 目标里最该学的那一颗 | 星的上方一个朱砂色的小菱形。目标的其余信息都在面板里，不画在图上 |
| 看不见的 | 不画。黑的就是黑的 |

## 字

- 中文一律 Noto Serif SC（宋体），数字用 Cormorant Garamond。没有无衬线字体。
- 星的名字：11px，字距 0.04em，墨·淡；亮星的名字用墨。
- 名字会避让：两个名字要叠在一起时，次要的那个不显示（亮星优先于边界星，边界星优先于其余）。
- 方向信标的名字：14px 宋体加粗。
- 大标题：26px 宋体 900。
- 界面文字：12.5px 到 13.5px，不加粗，靠字距和颜色区分层级。

## 布局与壳

- 星图占满整个窗口。壳只有两样东西：左上一行字（名字 + 亮了几颗），右上一行字（目标、下一颗、搜索）。
  它们没有背景，没有边框，直接写在夜上。
- 面板：右侧，夜·浅底，左边一根发丝线，没有圆角，没有阴影。
- 工具按钮：右下角竖排，只有符号，没有背景；悬停时变成墨色。
- 第一次打开：没有面板，没有欢迎卡，只有圆心的一团暖光和九颗起步星，下面一行小字“点一颗你已经会的星”。
- 选中一颗星：星旁边一张小卡，名字、一条学会的标志、“点亮”。

## 动效

- 慢。所有过渡 0.4s 以上，缓动 `cubic-bezier(0.2, 0.7, 0.2, 1)`。
- 点亮：星从 0 放大到 1.4 再回到 1，光晕扩散一次，0.9s。顺着星座线有一道光流到新解锁的星（dash 流动，一次）。
- 新出现的星：从 0 淡入放大，按离亮星的远近错开 60ms。
- 边界星的闪烁：不透明度 0.75 到 1，周期 5s，每颗起点随机。
- 禁止：呼吸式的缩放循环、持续旋转、弹跳。

## 不做的事

- 不做渐变标题、不做霓虹描边、不做卡片阴影堆叠、不做彩色图例盒子。
- 不同时显示所有标签。看不清就放大。
- 不用表情符号做图标。
