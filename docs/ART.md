# 美术风格：纸上的技能树

一句话：**一张印在白纸上、从中心往四周长的技能树。** 像动作游戏的天赋树：大量一条条的链，只在关键节点分叉，只用黑和灰。

参考物：游戏天赋树的分支结构、说明书里的线框示意图、javascript.info 那种只有正文和链接的教程页。
情绪：清楚、安静、一眼看懂。点亮一个技能就是把一个空方块涂黑。

## 颜色

| 名字 | 值 | 用在哪 |
| --- | --- | --- |
| 纸 `--paper` | `#ffffff` | 底色 |
| 墨 `--ink` | `#111111` | 文字、已掌握的节点、能学的节点的框、按钮 |
| 墨·淡 `--ink-2` | `#666666` | 次要文字、分支名 |
| 墨·极淡 `--ink-3` | `#9a9a9a` | 等级名、够不着的节点里的图标和名字 |
| 线 `--line` | `#d9d9d9` | 够不着的节点的框、未点亮的连线 |
| 线·淡 `--line-2` | `#ededed` | 等级之间的横线、列表分隔 |
| 洗 `--wash` | `#f4f4f4` | 悬停的底 |
| 朱砂 `--goal` | `#d94f3d` | 只用在两处：顶栏的目标名、“下一个”节点上方的小三角 |

规则：整张图只有黑白灰。唯一的颜色是朱砂，只给目标。没有渐变、没有阴影、没有圆角大于 4px 的东西。

## 节点

两种节点，一眼分得开：

- **课程**：54 的圆角方块，里面是课号（61A、213、S081……）。CS 核心课在中心，专业课在各自的枝上。
- **技能**：直径 54 的圆，里面一个 24px 的图标。

下面都是 13px 的名字。名字带一圈 5px 的白边，枝条从字下面穿过时不会和字搅在一起。
**每个技能一个自己的图标**：语言、框架、工具用官方 logo（Simple Icons），其余用 Lucide 里意思最直白的那个。体检会拒绝两个技能共用图标。

技能的颗粒度：**能写进简历的一项扎实能力**，比如 Python、Docker、CUDA、vLLM 推理、操作系统内核。知识点（哈希表、虚拟内存）不单独成节点。

| 状态 | 画法 |
| --- | --- |
| 够不着 | 浅灰圆框，浅灰图标和名字 |
| 能学 | 黑框 2px，黑图标，黑名字 |
| 在学 | 黑虚线框 |
| 已掌握 | 实心黑，白图标，名字加粗 |
| 选中 / 悬停 | 框加粗到 3px；它的前置路线和它解锁的保持清楚，其余淡到 22% |
| 目标里最该学的 | 圆上方一个朱砂小三角 |

## 结构

- **一棵树，从中心往四周长。** 中心一个小黑点，三根主干：61A（编程）、18.06（数学）、Linux（工具）。越往外越深。
- **每个节点只画一根枝**，连到它的主前置。所以画出来是一条条链：18.06 → 概率 → 229 → PyTorch → 224n → GPT → vLLM → 分布式推理 → 推理工程师。只有 61A、213 这种关键节点才一分多。
- **其余前置平时不画**。悬停或选中一个技能时，用细虚线补出来，整条路线变黑，其余淡到 22%。
- **枝头是方向**：一个小菱形和加粗的名字，名字写在外侧。点它，树上亮出它要学的全部技能，视图缩到正好装下这条路线。目标方向是朱砂色。
- **主线 AI Infra 朝上**，底层系统在右，AI 产品在左，安全、机器人、量化在下面。
- **位置**：枝头沿一圈等距排开，父节点在孩子们的中间，只有一个孩子时和它对齐，链是直的。每一圈的半径够放下名字，再加一点固定的抖动，不像尺子画的。
- **枝条**：径向的三次贝塞尔，从父节点沿径向出去再弯到子节点，像树枝，互相不交叉。已掌握之间的枝是黑的、粗一点；从已掌握长出去的是中灰；其余浅灰；通向方向的最后一段是点线。
- **打开时**不看全图：从中心的核心课看起，字看得清；往外拖或点“看全图”再看枝头。

## 字

- Noto Sans SC，没有衬线。
- 节点名 13px；课号 13px 粗体；方向名 14px 粗体。
- 面板标题 24px 700；正文 14.5px；小标题 12px 字距 0.15em 灰色。

## 面板

点进去只有：所属分支和等级、名字、一句话、三段开关（没学 / 在学 / 已掌握）、“去哪学”的链接、“先会”的前置名字。
没有列表轰炸。方向的面板同理：一句话、离它多远、设为目标、几个代表项目的链接。

## 壳

- 顶栏是一行字：左边名字和“已掌握 / 总数”，右边快速点亮、目标、下一个、搜索。下面一根浅线。
- 整个下方都是网。滚轮缩放、拖动平移、双指缩放，右下角放大、缩小、看全图。
- 右侧面板：选中节点时打开，网往左让，不盖住。手机上是底部抽屉。

## 动效

- 过渡 0.3 到 0.35s。点亮时方块弹一下（0.8 → 1.12 → 1），新解锁的线上有一道短划流过去。
- 禁止循环动画。
