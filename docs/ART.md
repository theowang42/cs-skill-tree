# 美术风格：纸上的技能树

一句话：**一张印在白纸上、从下往上长的技能树。** 像动作游戏的技能树：一列一列，大量一条条的链，只在关键节点分叉，最上面一排是要去的方向。只用黑和灰。

参考物：游戏天赋树的分支结构、说明书里的线框示意图、javascript.info 那种只有正文和链接的教程页。
情绪：清楚、安静、一眼看懂。点亮一个技能就是把一个空方块涂黑。

## 颜色

| 名字 | 值 | 用在哪 |
| --- | --- | --- |
| 纸 `--paper` | `#ffffff` | 底色 |
| 墨 `--ink` | `#111111` | 文字、已点亮的节点、能点亮的节点的框、按钮 |
| 墨·淡 `--ink-2` | `#666666` | 次要文字、分支名 |
| 墨·极淡 `--ink-3` | `#9a9a9a` | 等级名、够不着的节点里的图标和名字 |
| 线 `--line` | `#d9d9d9` | 够不着的节点的框、未点亮的连线 |
| 线·淡 `--line-2` | `#ededed` | 等级之间的横线、列表分隔 |
| 洗 `--wash` | `#f4f4f4` | 悬停的底 |
| 朱砂 `--goal` | `#d94f3d` | 只用在两处：顶栏的目标名、“下一个”节点上方的小三角 |

规则：整张图只有黑白灰。唯一的颜色是朱砂，只给目标。没有渐变、没有阴影、没有圆角大于 4px 的东西。

## 节点

直径 54 的圆，里面一个 24px 的图标，下面 13px 的名字。名字直接说它是什么（数据结构、操作系统、PyTorch），不写课号。
**每个节点一个自己的图标**：语言、框架、工具用官方 logo（Simple Icons），其余用 Lucide 里意思最直白的那个。体检会拒绝两个节点共用图标。

颗粒度：**能写进简历的一项扎实能力**。计算机核心课（数据结构、计算机系统、操作系统、计算机网络……）也是节点，链接指向公认最好的那门课。知识点（哈希表、虚拟内存）不单独成节点。

**只有两种状态：点亮了，和没点亮。** 没点亮的再按前置分成能点和还够不着，只是画法不同。
**前置都点亮了才能点亮**；取消一个，依赖它的一起熄灭（可以撤销）。够不着的节点在面板里按钮是灰的。

| 状态 | 画法 |
| --- | --- |
| 够不着 | 浅灰圆框，浅灰图标和名字 |
| 能点亮 | 黑框 2px，黑图标，黑名字 |
| 已点亮 | 实心黑，白图标，名字加粗 |
| 选中 / 悬停 | 框加粗到 3px；它的前置路线和它解锁的保持清楚，其余淡到 22% |
| 目标里最该学的 | 圆上方一个朱砂小三角 |

## 结构

- **从下往上长。** 最下面一排是起点：编程入门、微积分、Linux。往上一排深一层。
- **一列一列**：每个节点只画一根枝，连到它的主前置。所以画出来是一条条竖直的链，比如 Python → NumPy → 机器学习 → 深度学习 → PyTorch → Transformer → 从零实现 GPT → vLLM 推理 → 分布式推理。只有编程入门、Python、计算机系统这种关键节点才一分多。
- **左右的顺序**：AI 产品在左，主线 AI Infra 在中间，底层系统和安全在右，数学、量化和工具在最右。
- **其余前置不画线**（会横穿整张图）。悬停或选中一个技能时，它的全部前置和它解锁的保持清楚，其余变淡；面板里列出每个前置点亮了没有。
- **最上面一排是方向**：一个菱形，上面是加粗的名字和进度，从它挂的技能一根点线直直连上去。点它，树上亮出它要学的全部技能，视图缩到正好装下这条路线。目标方向是朱砂色。
- **枝条是直角折线**：从父节点顶上出发，往上到两排中间，横过去，再往上停在孩子名字的下面。拐角是小圆角。线永远不穿过字。已点亮之间的枝是黑的、粗一点；从已点亮长出去的是中灰；其余浅灰。
- **打开时**不看全图：原大小，从最下面的起点看起，主线在屏幕中间；往上拖或点“看全图”再看方向。

## 字

- Noto Sans SC，没有衬线。
- 节点名 13px；方向名 14px 粗体。
- 面板标题 24px 700；正文 14.5px；小标题 12px 字距 0.15em 灰色。

## 面板

点进去只有：所属领域、名字、一句话、一个“点亮”按钮、“去哪学”的链接、“先会”的前置名字。
没有列表轰炸。方向的面板同理：一句话、离它多远、设为目标、几个代表项目的链接。

## 壳

- 顶栏是一行字：左边名字和“已掌握 / 总数”，右边快速点亮、目标、下一个、搜索。下面一根浅线。
- 整个下方都是网。滚轮缩放、拖动平移、双指缩放，右下角放大、缩小、看全图。
- 右侧面板：选中节点时打开，网往左让，不盖住。手机上是底部抽屉。

## 动效

- 过渡 0.3 到 0.35s。点亮时方块弹一下（0.8 → 1.12 → 1），新解锁的线上有一道短划流过去。
- 禁止循环动画。
